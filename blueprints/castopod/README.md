# Castopod

Castopod is a free, open-source podcast hosting platform made for podcasters who want to engage and interact with their audience. Publish your podcast and episodes, follow download analytics, let listeners comment and share, and federate with the Fediverse over ActivityPub — with Podcasting 2.0 features (transcripts, chapters, funding, value4value…) built in.

## How this deployment works

This template deploys Castopod's **official Docker image** (`castopod/castopod`) with the two services it needs, following the upstream Docker guide:

- **castopod** — the app itself (FrankenPHP/Caddy all-in-one image), listening on port 8080 internally; your Dokploy domain terminates HTTPS in front of it.
- **mariadb** — the MySQL-compatible database Castopod requires.
- **redis** — used as the cache handler, as recommended upstream.

Uploaded media (audio files, cover art) is stored in the `castopod-media` volume; the database lives in `castopod-db`.

All passwords (database user, database root, Redis) and the analytics salt are **generated by Dokploy at deploy time** — there is nothing to fill in before deploying.

## First run

1. Deploy the template and wait until the `castopod` service is healthy (the first boot runs the database migrations).
2. Open `https://your-domain/cp-install` in your browser.
3. Create the super admin account and finish the installation wizard — after that, the installer page locks itself and you can sign in and create your first podcast.

## Notes

- HTTPS is mandatory for ActivityPub federation to work; Dokploy provides it automatically on your domain.
- Email sending is optional: to enable it, add the `CP_EMAIL_*` variables (SMTP host, from address, credentials) to the stack's environment in Dokploy and redeploy.
- To store media on S3 instead of the local volume, set the `CP_MEDIA_S3_*` variables in the stack's environment.
