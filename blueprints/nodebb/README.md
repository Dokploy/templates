# NodeBB

NodeBB is a modern discussion platform built on Node.js — the successor to classic forum software. Topics and replies update in real time, with categories, tags, private chats, notifications, a plugin system and themes, and an admin panel that covers everything from user management to spam control.

## How this deployment works

This template follows upstream's own Docker Compose example, using the **official image** (`ghcr.io/nodebb/nodebb:4.16.9`):

- **Two services:** NodeBB itself (port 4567) and a MongoDB sidecar (`mongo:7-jammy`, the same image upstream's compose uses). NodeBB also supports Redis or PostgreSQL as its database upstream; MongoDB is the reference setup.
- **Persistence:** three volumes mirror upstream's layout — `config` (`/opt/config`, where the installer writes `config.json`), `build` (`/usr/src/app/build`) and `uploads` (`/usr/src/app/public/uploads`) — plus `mongo-data` for the database.
- **One generated secret:** the MongoDB root password is generated by Dokploy at deploy time and wired through `template.toml`.

## First run

With no `config.json` present, the image starts NodeBB's **web installer** instead of the forum. Open your Dokploy domain and complete it:

1. **URL:** `https://<your-domain>` (the installer pre-fills it — keep it in sync with the domain).
2. **Database:** MongoDB, with:
   - Hostname: `mongo`
   - Port: `27017`
   - Username: `nodebb`
   - Password: the `MONGO_PASSWORD` value from this app's **Environment** tab in Dokploy (generated at deploy time)
   - Database name: `nodebb`
3. Create the administrator account when the installer asks.

After the installer finishes, NodeBB restarts into the forum itself. The MongoDB password is only applied when the database first initialises, so do not change `MONGO_PASSWORD` afterwards without also changing it inside MongoDB.
